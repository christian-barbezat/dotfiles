# Orthodox CLI Scripts

This repository contains personal command-line tools intended to support the daily rhythm of Orthodox Christian prayer and devotion. Each script is designed to be run in the terminal and provides liturgical or spiritual content for the day.

## Available Scripts

### `daily-psalter`

Displays one full Kathisma from the Psalter each day, following the Orthodox liturgical cycle. The text is drawn from the Septuagint, rendered in traditional English.

### `fasting-daily`

Shows the fasting rule for the current day, according to the Julian (Old) Calendar. This includes fast-free periods, fasting seasons, and fixed feast days.

### `prologue-daily`

Fetches and formats the daily reading from the *Prologue of Ohrid*, including the lives of the saints, hymns, reflections, and homilies.

### `scripture-daily`

Displays the appointed Scripture readings for the current day in the Orthodox calendar.
